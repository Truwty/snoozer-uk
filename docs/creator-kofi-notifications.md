# Creator Ko-fi external payment notifications

An individual creator can now opt in on Studio > Ko-fi notifications by entering the verification token from their own Ko-fi Webhooks settings. Snoozer stores only SHA-256 of the token, never the raw value; a new token rotates the digest, and Disable immediately stops accepting new records. The creator must configure the HTTPS webhook endpoint in their own Ko-fi account.

This is **not** a trustworthy net revenue ledger: the Ko-fi webhook is a shared-token notification feed, not signed, retrievable settlement, refund or cancellation proof. Never use these reports for tax-ready invoices, payout settlement, refunds, delivery, Snoozer Plus, or creator membership access. Only Donation events are recorded. Other Ko-fi event types are acknowledged and ignored. Each received notification retains only message UUID, transaction ID, UTC time, amount in original currency minor units, and profile ownership. GBP and USD remain separate. No supporter email, name or message is stored. Database review and profile ownership use verified users; anonymous and direct-table access are denied; service-role only can record a notification.

Ko-fi provider docs: https://help.ko-fi.com/hc/en-us/articles/360004162298-Does-Ko-fi-have-an-API-or-webhook
